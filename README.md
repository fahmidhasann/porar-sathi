# পড়ার সাথী — সেটআপ গাইড (তোমার জন্য)

ইংরেজি ট্রেনিং PDF বাংলায় বোঝার ফ্রি অ্যাপ (PWA)। ফোনে অ্যাপের মতো ইনস্টল হয়।

## কী কী পারে
- **শব্দে চাপ → বাংলা অর্থ + বাংলা অক্ষরে উচ্চারণ** (আগে ৮০+ procurement শব্দের নিজস্ব ডিকশনারি → তারপর AI → শেষে Google Translate)
- **বাংলায় বুঝাও** — প্রতি পৃষ্ঠার সহজ বাংলা ব্যাখ্যা + উদাহরণ + জরুরি শব্দ
- **শুনাও** — বাংলা ব্যাখ্যা জোরে পড়ে শোনায় (ফোনের নিজস্ব ভয়েস, ফ্রি)
- **কুইজ** + **রিভিশন** (যত শব্দে চাপ দিয়েছেন সব জমা থাকে)
- **বড় লেখায় পড়ুন** — বড় ফন্টে লাইন, প্রতি লাইনে 🔊
- একবার AI ব্যাখ্যা আনা হলে ফোনে সেভ থাকে → পরে ইন্টারনেট ছাড়াই দেখা যায়

## ১. অনলাইনে তোলা (ফ্রি, ৫ মিনিট)
```bash
cd app && npm install && npm run build
```
তারপর যেকোনো একটা:
- **সবচেয়ে সহজ:** https://app.netlify.com/drop খুলে `app/dist` ফোল্ডারটা টেনে ছেড়ে দাও → `https://….netlify.app` লিংক পাবে।
- অথবা GitHub Pages / Cloudflare Pages-এ `dist` ফোল্ডার।

(HTTPS লাগবে — নাহলে ইনস্টল আর Share কাজ করবে না। উপরের সবগুলোতেই HTTPS আছে।)

## ২. আম্মুর ফোনে সেটআপ (একবার)
1. ফোনে **Chrome** দিয়ে লিংকটা খোলো → ⋮ মেনু → **"Add to Home screen" / "Install app"**।
2. অ্যাপে ⚙️ → https://aistudio.google.com/apikey থেকে ফ্রি Gemini key বানিয়ে বসাও → **"সেভ ও পরীক্ষা"** → ✅ দেখলে ঠিক।
3. একই পাতায় **"বাংলা শুনুন"** চাপো। বাংলা না শোনালে: ফোনের Settings → Text-to-speech → Google Speech Services → Install voice data → বাংলা (বাংলাদেশ)।
4. লেখার সাইজ আম্মুর চোখ অনুযায়ী বাড়িয়ে দাও।
5. WhatsApp-এ একটা PDF-এ চেপে ধরে → Share → **পড়ার সাথী** — একবার দেখিয়ে দাও।

## খরচ ও সীমা
- সব ফ্রি। Gemini free tier-এ দিনে যথেষ্ট রিকোয়েস্ট (একটা ২১ পৃষ্ঠার PDF ≈ ২১টা)।
- "একটু বেশি প্রশ্ন হয়ে গেছে" দেখালে ১ মিনিট অপেক্ষা।
- ফ্রি key-তে Google লেখা দেখতে পারে → শুধু ট্রেনিং ম্যাটেরিয়াল, ব্যক্তিগত কাগজ না।

## লোকালি চালানো
```bash
cd app && npm run dev
```

## ফাইল
- `src/reader.ts` — PDF দেখা, শব্দ-ট্যাপ, বাটনগুলো
- `src/ai.ts` — Gemini prompt (মডেল অটো-ফলব্যাক: `gemini-flash-latest` → `gemini-2.5-flash` …)
- `src/glossary.ts` — procurement শব্দভান্ডার (নতুন শব্দ এখানে যোগ করো)
- `src/sw.ts` — অফলাইন + WhatsApp Share গ্রহণ
